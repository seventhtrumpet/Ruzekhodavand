# Persian Old Persian Version (OPV) data

Source: https://ebible.org/bible/details.php?id=pesOPV

The source identifies OPV as public domain and credits Wycliffe Bible Translators.
Original USFM archive: https://ebible.org/Scriptures/pesOPV_usfm.zip

Generated as one JSON file per Bible book for the reader, plus index.json for full-text search.
The source has two intentionally preserved empty verse markers in Job 35:1 and 40:1.
The source placed the wording of Ezekiel 25:5 at the end of 25:4; the build restores that verse boundary without changing the wording.
