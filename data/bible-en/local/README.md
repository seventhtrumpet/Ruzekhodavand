# Local English public-domain Bible texts

Sources: official eBible.org VPL archives, pinned by SHA-256 in metadata.json.
Included editions: WEB Classic, ASV 1901, YLT 1898, Webster 1833, Darby 1884, Geneva 1599, and BSB.
The VPL format contains Bible text only. The importer preserves verse wording and includes the 66 standard books. Empty verse markers are preserved and never filled from another edition.
The World English Bible name is retained only for the unchanged source text.
