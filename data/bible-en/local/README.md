# Local English public-domain Bible texts

Sources: official eBible.org VPL archives, pinned by SHA-256 in metadata.json.

Included editions: WEB Classic and WEBBE each contain 81 source book/text units (66 common books plus 15 additional texts); ERV 1885 contains 80 (66 plus 14); DRA contains 73 (66 plus seven). ASV 1901, YLT 1898, Webster 1833, Darby 1884, Geneva 1599, BSB, and MSB contain 66 source books. DRA also includes the longer Esther and Daniel chapter divisions.

The VPL format contains Bible text only. The importer preserves source verse wording, empty verse markers, and verse-number gaps; it never fills missing text from another edition. Esther (Greek) in ERV 1885 is supplied as source chapters 10–16 and retains those chapter numbers.
