# Local English public-domain Bible texts

Sources: official eBible.org VPL archives, pinned by SHA-256 in metadata.json.
Included editions: WEB Classic, ASV 1901, YLT 1898, Webster 1833, Darby 1884, Geneva 1599, BSB, ERV 1885, Douay-Rheims 1899, WEBBE, and MSB. The official WEB Classic VPL archive contains 81 book/text units (66 common books plus 15 Deuterocanonical/Apocryphal texts); DRA and WEBBE each contain 73 books (66 plus seven deuterocanonical books). DRA also includes the longer Esther and Daniel chapter divisions.
The VPL format contains Bible text only. The importer preserves source verse wording, empty verse markers, and verse-number gaps; it never fills missing text from another edition. WEB Classic's additional texts are separate source books/sections and are not silently merged into the 66 common books.
The World English Bible name is retained only for the unchanged source text. The Majority Standard Bible is identified as Public Domain by its official eBible.org source.
