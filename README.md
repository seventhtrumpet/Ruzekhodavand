# Ruzekhodavand / Church of God

**Three Angels' Message — Revelation 14**

Public bilingual (Persian default + English) website for Bible-related photos, videos, texts and files.

- Legacy admin panel: client-side demo only; it is not secure authentication and must not protect sensitive or shared data.
- Visitors can view, download and comment
- Folders by Bible book
- Text / writings support
- Date & time for posts
- Go Live feature
- Mobile friendly

## Deploy to Netlify
1. Connect this repository to Netlify
2. Or drag the files to [app.netlify.com](https://app.netlify.com)

## Admin
- Open `/admin.html` only if access is restricted outside the application.
- Do not rely on the legacy client-side login as an access-control boundary. A server-side authentication and authorization migration is required before using this panel with shared or sensitive data.
